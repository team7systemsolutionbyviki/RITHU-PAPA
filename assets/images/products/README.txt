🌸 ART_SHINERSSS - HOW TO AUTOMATICALLY ADD PRODUCTS VIA IMAGE NAMES
================================================================================

Drop your jewellery photos directly into this folder (assets/images/products/)
and name them using any of these simple formats:

FORMAT 1 (Recommended):
  Category_Product Name_Price.jpg
  Example:
  Handmade Bracelets_Rose Quartz Glamour Bracelet_399.jpg
  Beaded Bracelets_Pastel Crystal Charm Bracelet_450.jpg
  Handmade Chains_18K Gold Paperclip Choker_499.jpg
  Pendant Chains_Baroque Pearl Floral Pendant_549.jpg
  Customized Name Jewellery_Initial Letter Set_420.jpg
  Bracelet and Chain Gift Sets_Luxe Celebration Hamper_899.jpg

FORMAT 2 (Hyphen separated):
  Category - Product Name - Price.jpg
  Example:
  Handmade Bracelets - Rose Quartz Glamour Bracelet - 399.jpg
  Friendship Bracelets - Pastel Sunset BFF Stack - 349.jpg

FORMAT 3 (Name first):
  Product Name_Price_Category.jpg
  Example:
  Royal Velvet Hamper_899_Gift Sets.jpg

--------------------------------------------------------------------------------
SUPPORTED CATEGORIES:
--------------------------------------------------------------------------------
- Handmade Bracelets
- Beaded Bracelets
- Friendship Bracelets
- Handmade Chains
- Necklaces
- Pendant Chains
- Customized Name Jewellery
- Bracelet and Chain Gift Sets

--------------------------------------------------------------------------------
HOW TO SYNC:
--------------------------------------------------------------------------------
1. Drop your renamed image(s) into this folder.
2. Double-click the file "sync_products.bat" in the main project folder.
   (Or in terminal run: python update_products.py)
3. Done! The product is automatically added to products.js and appears on your website immediately!
